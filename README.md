# Jaid Sutar Resume

Static React + Vite resume portfolio, hosted on Netlify.

## Run locally

```bash
npm install
npm run dev
```

The contact link uses `mailto:` to open the visitor's email application with your address filled in. They send the message from that app; the static site does not send or store email itself.

For Netlify, run `npm run build` and publish the `dist` directory.
